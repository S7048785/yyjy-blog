## 个人博客 (半成品)

### 项目介绍

+ 该项目是基于 Springboot + Vue3 开发的前后端分离的个人博客项目
+ 前台布局和样式借鉴于 CSDN、稀土掘金、https://vio.vin

Q：为什么项目做到一半不做了？

A：从项目部署到停止开发一共经历18天，期间花费大量时间在网页样式布局上，虽然学到了不少技术并运用在项目中，但因为总是出现一些bug，让我觉得很无聊很麻烦。而我在休闲期间发现了新奇的技术，比如kotlin、jimmer、Nuxt3，这让我对这个项目产生了厌倦，再这样下去的话只会浪费时间，所以就选择放弃，下次再来尝试复现吧。

PS：其实我前面还有两个也是半途中就放弃的web项目。。。
